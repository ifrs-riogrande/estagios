Carregando…
O sistema executa um verificador diário automático que dispara lembretes antes do vencimento e reenvios após o vencimento, por fluxo. Configure cada fluxo individualmente abaixo.
Checklist de Solicitação Lembretes para o ator ativo do checklist (orientador, supervisor, coordenador ou admin) quando o prazo de resposta estiver próximo ou vencido.
Ativo
Envia 1 lembrete quando restar exatamente este número de dias úteis antes do prazo. Sábados e domingos não contam.

Avisos após o vencimento

Após o vencimento, reenvia o lembrete a cada N dias úteis. Ex: 3 = reenvia no 3º, 6º, 9º dia útil após o prazo.
Número máximo de reenvios pós-vencimento. Após atingir o limite, o sistema para de enviar automaticamente e o admin deve intervir manualmente.
A partir deste reenvio pós-vencimento, uma cópia do lembrete é enviada também para o admin. Ex: 2 = nos reenvios 2, 3, 4… o admin é copiado.

º reenvio

Assinaturas do TCE Lembretes para o signatário ativo do TCE (estudante, empresa, DG ou central) quando o prazo de assinatura estiver próximo ou vencido.
Ativo
Envia 1 lembrete quando restar exatamente este número de dias úteis antes do prazo de assinatura.

Avisos após o vencimento

Após o vencimento, reenvia o lembrete a cada N dias úteis.
Número máximo de reenvios pós-vencimento para este fluxo.
A partir deste reenvio pós-vencimento, o admin também é copiado no lembrete.

º reenvio

Avaliações de Estágio Lembretes para o preenchedor ou revisor de avaliação (supervisor, orientador, coordenador) quando o prazo estiver próximo ou vencido.
Ativo
Envia 1 lembrete quando restar exatamente este número de dias úteis antes do prazo de avaliação.

Avisos após o vencimento

Após o vencimento, reenvia o lembrete a cada N dias úteis.
Número máximo de reenvios pós-vencimento para avaliações.
A partir deste reenvio pós-vencimento, o admin também é copiado.

º reenvio

Adendo / Aditamento ao TCE Lembretes para o signatário ativo do fluxo de adendo (alteração de dados do estágio em andamento) quando o prazo estiver próximo ou vencido.
Ativo
Envia 1 lembrete quando restar exatamente este número de dias úteis antes do prazo do adendo.

Avisos após o vencimento

Após o vencimento, reenvia o lembrete a cada N dias úteis.
Número máximo de reenvios pós-vencimento para adendos.
